# gh-agent

This extension uses AI to generate content for pull requests and reviews,
powered by AI-agent and [gum](https://github.com/charmbracelet/gum).

## Installation

```bash
gh extension install gh-extensions/gh-agent
```

## Getting Started

This extension provides AI-powered assistance for common GitHub workflows:

- **Git Commit** - automatically generates a conventional commit.
- **GitHub Pull Request Creation** - automatically generates a descriptive title
  and body for your pull request.
- **GitHub Pull Request Review** - automatically generates a comprehensive
  review comment for a pull request.

```bash
# Show help for available commands
gh opencode --help
```
